# goldcut · 金剪（本机技能副本）

这是 [wallstreet-explainer](https://github.com/HeyChengC/wallstreet-explainer) 的本机副本，改名 **goldcut（金剪）**：
金是它的颜色（金色大数字、鎏金渐变），剪是它的手艺（手法库 moves.js、逐帧量的缓动、运动模糊、承接逻辑）。

与上游的差异只有两处：

1. `SKILL.md`：`name: goldcut`，触发语加了"金剪""goldcut"
2. `scripts/local.json`：字体目录指向本副本的 `fonts/`

用法不变：在对话里说"用金剪做一条财经/科技解读短片"即可。
已产出的两条试片：`E:\poc\films\nvda-500b`（横屏 16:9）、`E:\poc\films\gold-drop`（竖屏 9:16，接缝小标"金剪"）。

上游 MIT 协议，本副本同样遵循；样片里的第三方素材出处见各片 `BRIEF.md`。
